How to read this

  • Colour is the runner CPU model. On shared CI runners the CPU changes between jobs and moves the medians; that is why each push is judged inside its own job, against its base, and the history only advises.
  • The gate row under each chart shows that per-push verdict: grey no regression, red a regression of this metric, outlined invalid. A red ring marks the same point on the trace.
  • A dashed amber line is an advisory change point: E-Divisive on the latest 20 points with the benchmarkIndex adjustment learned from earlier points (docs/history-cpd.md). It never fails a job; in the research data it also fired without a change in up to 17% of windows on some series.
  • Dotted lines mark a Chrome version change; the ringed point is the latest measurement.
